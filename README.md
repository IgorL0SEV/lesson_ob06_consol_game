# ⚔️ Консольная игра "Время героев"

Небольшая текстовая консольная игра на Python, в которой два героя — игрок и компьютер — сражаются друг с другом до победы одного из них.
Проект для практики ООП на Python.

## 🧠 Логика игры

- У каждого героя есть **здоровье** (100 единиц) и **сила удара** (начально 20).
- Каждый ход:
  - Герой атакует противника, уменьшая его здоровье.
  - Сила удара случайно изменяется (от 1 до 20) на следующий ход.
- Игра продолжается, пока здоровье одного из героев не упадёт до нуля или ниже.
- Выводятся подробности каждого хода и объявляется победитель.

## 📦 Структура кода

- `Hero` — класс героя:
  - `attack()` — наносит урон противнику.
  - `is_alive()` — проверяет, жив ли герой.
  - `info_health()` — отображает текущее состояние героев.

- `Game` — игровой процесс:
  - `start()` — управляет ходами, чередует атаки игрока и компьютера, отслеживает победу.

## ▶️ Как запустить

1. Склонируйте или скачайте проект.
2. Убедитесь, что установлен Python 3.7+.
3. Запустите файл main.py .

Чередует ходы игрока и компьютера, 
пока один из героев не погибнет. 

Выводит информацию о каждом ходе 
(кто атаковал и сколько здоровья осталось у противника) 
и по результатам сражения, - объявляет победителя.
